

Morse code is a method of communication that uses a series of dots (.) and dashes (-) to represent letters, numbers, and punctuation. It was one of the earliest forms of long-distance communication and was mainly used with the telegraph
Morse code was developed in the 1830s and 1840s by Samuel Morse and Alfred Vail. It was created to send messages over telegraph systems using electrical signals. During the late 19th and early 20th centuries, Morse code became the standard method of communication for railways, ships, the military, and emergency services. 
Morse code represents each letter and number with a unique pattern of dots and dashes.
